## 🔧 Kluczowe gotchas / lekcje

- ⭐ **PUŁAPKA „zamrożonego exe"** [[desktop-rebuild-stale-exe-trap]] (kosztowała godziny): `dotnet -t:Run` z działającą instancją CICHO odpala STARY exe (lock), a `taskkill //PID` z Git Bash jest ZAWODNY (`//` mangling). **Kill PowerShellem + sprawdzaj datę WŁAŚCIWEGO DLL**: zmiana w App (VM/View/Service) → `MapaTur.App.dll`; zmiana w libie → `MapaTur.<Lib>.dll`; **NIE** `MapaTur.App.exe` (host rzadko się zmienia). Build FAIL (np. CS0165) + `-t:Run` też odpala stary plik. Niezawodna sekwencja: PS kill→potwierdź zero→build→sprawdź mtime DLL→`Start-Process`.
- ⭐ **„oble" na telefonie = BRAKUJĄCE kafle** [[mobile-verify-full-tile-cache]], NIE budżet/glue. Bundlowana paczka ~4265 z lukami; desktop ~7338. Sprawdzaj po KAŻDYM reinstalu (procedura w CLAUDE.md). Transfer: `tar --force-local -T missing.txt` → `adb push /data/local/tmp` + `chmod 644` → `run-as tar -xf` (STDIN-pipe przez `adb exec-out run-as` WISI — nie używać). Push 810 MB = 12 s @66 MB/s.
- **Log desktopu**: `…\win-x64\logs\mapatur-<data>.log` (Serilog; stdout `-t:Run` PUSTY). Log telefonu: `files/logs/mapatur-*.log` przez `run-as` (Debug build). Czytaj UTF-8 (polskie znaki) + `PYTHONIOENCODING=utf-8` na stdout.
- **Diagnostyka na telefonie**: badge „Diagnostyka LOD" (Ustawienia→DEBUG) = ground truth; `cache-only z16: cached=X/144` mówi czy kafle są. Per-tile build odpala się DOPIERO przy ruchu kamery (look-at focus) — statyczny launch nie przeliczy.
- **Honoratka i żleby/rynny NIE w OSM** — Honoratka curated (na Zmarzłej Przełączce Wyżniej).
- **Komentarze XML w libach format-gated**: `<` / `>` w `///` = CS1570 (parsuje jak tag). Final-newline: `.editorconfig` zabrania w Domain/Application/Infrastructure/Routing — trimuj po `Write` nowych .cs.
