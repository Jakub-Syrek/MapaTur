# Perennial firn ("lodowczyki" / glacierets) — procedural generation

The white perennial-snow tongues in the high cirques (e.g. the couloirs above Czarny Staw pod Rysami) are
generated procedurally, but the **WHERE comes from data** and the procedure only shapes the tongue inside each
documented site — the same data-first pattern as lakes and summits.

Source: `PerennialFirn.cs`, `FirnSiteData.cs`, `MountainStreamData.g.cs` (Application layer, pure + unit-tested),
mirrored per-fragment in `Terrain3DGlRenderer.cs`.

## 1. Physical premise — why not an altitude threshold

Above ~2000 m the presence of year-round snow in the Tatras stops being a function of altitude alone. The real
patches (Mięguszowiecki Kocioł, Bandzioch, pod Rysami) survive the summer on **local mass balance**: wind and
avalanches sweep snow from a whole catchment into a small cirque (accumulation ≫ direct snowfall), N-facing
walls shade it (minimal insolation), and 334 kJ/kg of latent heat buffers the melt. So the deciding variables
are **aspect (N vs S), terrain shape (cirque vs ridge) and deposition susceptibility** — not an elevation gate.

## 2. Data layer

- **`FirnSiteData.Sites`** — 9 curated glacieret sites. Each `FirnSite` = `Location` (centre) + `RadiusMeters`
  (feathered reach) + `MaxElevationMeters` (**tongue cap**: the deposition zone is the lower couloirs + floor;
  crags higher on the same wall, still inside the radius, stay bare rock — fixes the "przyprószenie" bug where
  firn fired on concave nooks high on the Rysy wall). Sites: Mięguszowiecki Kocioł / Bandzioch / Mały Kocioł
  Mięguszowiecki; Kocioł pod Rysami; Żleby Niżnich Rysów; Kotlina pod Wagą (SK); Kozia Dolinka / Dolinka Pusta /
  Dolinka pod Kołem (Orla Perć). The pod-Rysami sites are anchored to the lake-gazetteer geometry (an early cut
  sat ~600 m too far east and painted the sunlit ridge flank instead of the runouts over the water).
- **`MountainStreamData.g.cs`** — Tatra watercourses from OSM (generated by `testdata/maps/fetch-tatra-streams.py`),
  rasterised into the **R8 water mask** distance field. This is the *channel prior*: the real tongues lie exactly
  along the meltwater streams they feed. When the live waterways layer is empty the renderer falls back to this
  static `StaticFirnStreams` gazetteer (the firn field needs the real channel geometry even where the water
  **decal** is off for performance).

## 3. Model — `PerennialFirn.Weight(...) → [0,1]`

Pure and unit-tested (`PerennialFirnTests`); the shader mirrors it exactly from the same constants.

Inputs: `elevationMeters`, `northness = max(0, normal.y)`, `southness = max(0, -normal.y)`,
`concavity = 1 − AO` (normalised), `slopeCos = normal.z`, `channel` (proximity to a mapped watercourse, 0..1).

Constants: `LineMeters = 2000`, `RunoutDropMeters = 550`, `BandMeters = 300`, `SouthPenalty = 0.85`.

The key design decision is **CHANNEL-DOMINANT** (v6, photo-ground-truthed at Czarny Staw pod Rysami): the real
patches are narrow tongues in the couloir SLOTS the streams run down — NOT the broad avalanche apron on the
cirque floor, which the vertex-scale AO also reads as "concave" but which melts out in summer. So mapped-stream
proximity is the PRIMARY driver; broad AO concavity is a weak secondary that only counts when it also faces north.
(v1 used northness alone and glazed whole north faces with a milky film — wrong.)

```
broadConcave = smoothstep(0.20, 0.55, concavity)         // deep enclosed nooks only
depo         = max(channel, broadConcave)                // channel is primary

effLine = LineMeters − RunoutDropMeters · depo           // deposition holds snow LOWER
                                                         //   channel line 2000−550 = 1450 m → fan reaches
                                                         //   the Czarny Staw shore (~1583 m)
altGate = smoothstep(effLine − Band/2, effLine + Band/2, elevation)

shelter = clamp(channel + broadConcave·northness·0.5 + 0.10·northness − 0.85·southness, 0, 1)
                                                         // channel earns firn outright; a deep off-channel
                                                         // N nook a little; open/south ~nothing

cosBare = cos(SnowBaresAboveDegrees) − 0.25·depo         // mechanical hold, RELAXED in channels:
cosFull = cos(SnowHoldsBelowDegrees) − 0.20·depo         //   bed-anchored couloir firn clings to ~70°
hold    = smoothstep(cosBare, cosFull, slopeCos)

weight  = smoothstep(0.45, 0.72, altGate · shelter) · hold   // sharpen into DISCRETE tongues, high threshold
```

## 4. Shader (`Terrain3DGlRenderer`, per-fragment)

Gated by `uFirnStrength = 0.85` (the instant rollback lever), off in slope-visualisation mode, and only when
curated sites are present. Uniforms are scaled by the vertical exaggeration (`firnExag` = Pion) so the world-Z
gates track the mesh: `uFirnLineZ`, `uFirnBandZ`, `uFirnDropZ`, and each site's cap.

1. **Site mask** — loop over `uFirnSites[12]` (world XY + reach): `fSite = 1 − smoothstep(0.55·r, r, dist)`
   (feathered radial mask); `fCap = 1 − smoothstep(cap − 80, cap, worldZ)` (tongue cap → high crags stay bare).
2. **Concavity from baked AO** — `fConcave = (1 − vColor.a) / 0.6`: reuses the curvature AO baked into the vertex
   colour ALPHA.
3. **Channel** — sample `uWaterMask` (R8 distance field), `fwDist = (1 − fwA)·maxDist`; band width
   `fOuter = 12 + 28·fSpread + 10·noise`, where **`fSpread = clamp((uFirnLineZ − worldZ)/300 + 0.25)` splays the
   tongue wide downhill (the avalanche fan) and pinches it at the top** — this is what makes the tongue fan out to
   the lake shore. The ~10 m ragged edge is noise **dither only**. `fChannel` is wider in a concave couloir,
   pinches on a convex spur (`0.45 + 0.55·fBroad`).
4. The rest mirrors `PerennialFirn` 1:1 (`fDepo`, `fLine`, `fAlt`, `fShelter`, `fHold`) and folds into the snow
   path: `snowMix = max(snowMix, smoothstep(0.45,0.72, fAlt·fShelter)·fHold·fSite·fCap·uFirnStrength)` — the firn
   is shaded by the same snow material.

## 5. Seasonal snow shares the same signals

The snow slider abandoned random wind/curvature noise for the SAME real signals (AO + channels): it accumulates
in couloirs and is scoured off ridges — consistent with the firn, driven by terrain and mapped streams rather
than procedural noise.

## 6. Tuning / rollback

- `FirnStrength` (renderer const, 0.85) — 0 = firn off, the instant rollback lever.
- Per-site `RadiusMeters` / `MaxElevationMeters` in `FirnSiteData` — move/resize/cap a site against photos.
- Model constants in `PerennialFirn` (`LineMeters`, `RunoutDropMeters`, `BandMeters`, `SouthPenalty`) — the
  altitude line, how far runout tongues descend, the gate softness, and the south-exposure penalty.

> Lesson (do not re-diagnose): the fix took ~9 iterations against the user's own photos with a verdict each
> time; colour metrics misled (haze read as "not blue"), so the patches were tuned by READING the reference
> image, not by a scalar. CHANNEL-DOMINANT is the resolution — do not revert to northness-only (it glazes the
> whole bowl).
