## Co zrobione w tej sesji

### 1. Płynny streaming detalu LOD (GŁÓWNA robota) — `32d987f`
Film/przelot zarywał wielosekundowo przy każdym przeładowaniu okna detalu. Przyczyna: okno przebudowywało i
re-meshowało **cały ~340-kaflowy zestaw** co reload → churn Large Object Heap → przestoje GC ~1.5 s.
Architektura naprawiona **porządnie** (user wprost odrzucił precache i wyłączanie GC jako „lepienie z gówna"):
- **`PerTileMeshCache`** (`DetailBlockKey` = absolutne z16-piksele + step + edge-ratios + exaggeration) — niezmienione
  kafle są **reużyte jako te same obiekty**; renderer `SyncTiles` robi delta-upload po tożsamości → zero re-uploadu.
- **`DetailTileGrid.AbsoluteBoundaries`** — granice kafli snapowane do stałej absolutnej siatki (mozaika jest
  z16-aligned), więc tożsamość kafla jest stabilna przy ruchu okna. **Quantum = 250** (MUSI = `maxTileSide` w
  `TerrainMesh3D`; 256 dało 4× eksplozję kafli przez sub-cuty 2×2).
- **`PerTileRepairCache` / `PerTileRepair.RepairWindowCached`** — naprawa (`FillNarrowZeroStrips`+`FillPits`) per
  kafel z16 z marginesem, cache po (X,Y); udowodnione cell-for-cell identyczne z naprawą całego okna.
- **`MeshBufferPool`** (static `Shared`, dokładne kubełki, kill-switch `Enabled`) — wynajem/zwrot 5 dużych tablic
  wierzchołków; zwracane po GL-upload. Mozaika + detal-raster też z poola (recykling z 2-buildowym opóźnieniem).
- **In-place naprawy** (`HoleBelowInPlace`, `FillNoDataFromInPlace`) — mutują raster zamiast klonować ~90 MB.
- **Deferred upload** (`DrainTileUploads`, ≤6 kafli/klatkę) + **prekalkulowane world-AABB** w ctor `TerrainMesh3D`
  (`EnsureOrthoCellBounds` skanował WSZYSTKIE wierzchołki per swap = ~360 ms → teraz ~0).
- **Server GC** (Windows-only, szybszy równoległy Gen2) w `MapaTur.App.csproj`.
- **Tuning:** `LodDetailReloadCooldown=35000` ms, okno desktop 3500 m / mobile 2200 m, budżety desktop 48 M.
- **Diagnostyka:** frame-gap watchdog (gen2-delta + heap, loguje >150 ms), per-tile meshHit/Miss, repairMs,
  swap-hitch breakdown (sync/ortho/lake).
- **Efekt:** build 35 s→8 s, swap-hitch 360–1350 ms→~31 ms, heap 15 GB→~3 GB, zarywanie z ciągłego →
  **~2 blipy GC na cały film** (user: „1 ale ostrożnie" / „2 zarwania"). Reszta = nieusuwalny sufit Gen2 nad
  żywą stertą retencyjną (poole/cache) — patrz TODO.
