## 🔧 Kluczowe gotchas / lekcje

- **Badge LOD „dystans raz na 5 min" (desktop)** — `OnDetailFocusAsync` miało: top-guard `lodDetailLoading` (build detalu **15–26 s** z logu!) + gate `ShouldReload(drift look-at)` + cooldown. Czysty zoom nie przesuwa look-at → badge zamrożony. Fix (`55c6ac6`): tier/dystans/badge liczony PRZED wszystkimi gate'ami i NIE blokowany przez `lodDetailLoading` (ten blokuje już tylko sam rebuild). Cache `x/y` i `s#` nadal zmieniają się tylko po realnym reloadzie. `SerializeCamera` używa `:R` — event leci co 1.2 s (cameraSaveTimer), to nie on był winny.
- **Drogi przewodnickie = OSM (ODbL), nie trzeba kupować mapy.** mapa-turystyczna.pl renderuje je z OSM (`highway=path` poza relacją: sac_scale/trail_visibility/informal). Bazy TCX/GPX off-trail są własnościowe (Wikiloc/Strava/Komoot, ToS zabrania scrapowania). Legalna droga dla „pozaszlaków" usera = **import własnych śladów** (apka ma TCX; do dorobienia GPX). ⚠️ TPN: ruch poza szlakami zakazany — etyka/odpowiedzialność.
- **Honoratka i żleby/rynny NIE są w OSM.** Honoratka dodana ręcznie (curated). Żlebów/rynien nie da się „dodać wszystkich" — brak nazwanych w OSM.
- **Sterowanie szklanym menu pikselami (computer-use) jest ZAWODNE** — gesty widoku 3D (SKGLView) przechwytują automatyczne klik/klawisze (kamera się rusza, tekst leci do wyszukiwarki). Weryfikacja wzrokowa funkcji wymagających klikania w panele = na userze (ludzkie tapnięcie działa). Czysto da się: screencap, scroll(zoom), Win32 MoveWindow/SetForegroundWindow do ustawienia okna.
- **Bundlowane gazetteery** (`TatraHuts`, `TatraPasses`) to wzór jak `TatraSummits`: curated `MountainPoi`/`NamedSummit` z WGS84, negatywne id = curated, dedup po nazwie (pobrane OSM wygrywają). `Resources/Raw/tatra-osm-peaks.json` = bundlowany OSM `natural=peak` (parser `OverpassPeakResponseParser`, filtr ≥1500 m) — można by analogicznie dorzucić saddle, ale poszliśmy w curated `TatraPasses`.
- **Final-newline**: `.editorconfig` zabrania końcowego newline w libach format-gated (Domain/Application/Infrastructure/Routing). `Write` dodaje newline → TRIMUJ po Write nowych plików .cs w tych libach (robione przez PowerShell TrimEnd).
- **Deploy/wersjonowanie**: telefon — lokalny build podpisany z `signing.local.props` (ten sam klucz co CI), `adb install -r` zachowuje dane, **versionCode > obecnego** (vc145 → 146+); `-p:ApplicationVersion=N -p:EmbedAssembliesIntoApk=true`. CI „Latest APK" ma własny `run_number` jako vc (np. 84) — **niższy niż telefonowe vc145** → GitHubowy APK nie wgra się nad telefonem (downgrade); jest pod świeże instalacje. adb: `C:\Program Files (x86)\Android\android-sdk\platform-tools`.
